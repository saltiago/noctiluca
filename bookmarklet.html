Step 3 — Use it

Go to any page. Click + Noctiluca in your toolbar. A form appears — post and close.

How it detects content
  • If you've selected text on the page — opens as a Quote
  • If you're on a YouTube page — opens as a Video, pre-filled
  • If the URL is a direct image link — opens as an Image
  • Everything else — opens as a Thought
